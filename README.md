## 📖 Overview

This repository contains a complete Python implementation of the **Black Widow Optimization Algorithm (BWO)** and its extension **Multi-Objective Black Widow Optimization Algorithm (MOBWO)** based on the paper:

> *"Black Widow Optimization Algorithm: A novel meta-heuristic approach for solving engineering optimization problems"* 
> — Vahideh Hayyolalam, Ali Asghar Pourhaji Kazem (2020)

## ✨ Features

- ✅ **BWO**: Single-objective optimization for continuous problems
- ✅ **MOBWO**: Multi-objective optimization with Pareto dominance and crowding distance
- ✅ Vectorized operations for fast computation
- ✅ Comprehensive test suite with benchmark functions
- ✅ Visualization tools for convergence and Pareto fronts
- ✅ Easy-to-use API with configurable parameters
